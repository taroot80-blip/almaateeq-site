# جسر العطاء — النسخة المستقلة

برنامج قائم بذاته لتدوير المقتنيات المنزلية الفائضة: المتبرع يعرض الغرض، والمشرف يعتمده ويعلنه في مجموعة الواتساب، والمحتاجون يطلبونه بالكود، ثم يختار المشرف المستفيد ويرسل رسائل التأكيد للطرفين.

لا يعتمد على أي موقع آخر. يحتاج شيئين فقط، وكلاهما متاح مجاناً:
1. **قاعدة بيانات** على Supabase.
2. **مكان لنشر الملفات** (أي استضافة مواقع).

## محتويات الحزمة

| الملف | الوصف |
|---|---|
| `index.html` | البرنامج كاملاً (التصميم + البرمجة) |
| `logo.png` | شعار المنصة — استبدله بشعارك بنفس الاسم إن أردت |
| `icon-180.png` | أيقونة المتصفح والجوال |
| `install.sql` | ملف تثبيت قاعدة البيانات (يُشغَّل مرة واحدة) |
| `دليل_التشغيل.md` | هذا الدليل |

---

## الخطوة ١: إنشاء قاعدة البيانات (10 دقائق)

1. ادخل إلى **supabase.com** وأنشئ حساباً مجانياً.
2. اضغط **New project**، واختر اسماً (مثل `jisr`)، وكلمة مرور قوية لقاعدة البيانات (احفظها عندك ولا تضعها في أي ملف)، والمنطقة الأقرب لك (مثل Frankfurt).
3. بعد اكتمال الإنشاء افتح **SQL Editor** من القائمة الجانبية ← **New query**.
4. افتح ملف `install.sql` بأي محرر نصوص، انسخ محتواه كاملاً، الصقه، ثم اضغط **Run**. يجب أن تظهر رسالة نجاح.
5. افتح **Project Settings ← API** وانسخ:
   - **Project URL** (مثل `https://abcd1234.supabase.co`)
   - **المفتاح العام**: `anon` أو `publishable`. ⚠️ **ليس** مفتاح `service_role`.

## الخطوة ٢: ضبط البرنامج (5 دقائق)

افتح `index.html` بمحرر نصوص (Notepad++ أو VS Code)، وابحث عن **`const CONFIG`** في أعلى البرمجة، وعدّل:

```js
SUPABASE_URL: 'https://abcd1234.supabase.co',   // من الخطوة ١
SUPABASE_KEY: 'eyJhbGciOi...',                    // المفتاح العام
APP_NAME:  'جسر العطاء',                           // اسم المنصة
TAGLINE:   'حفظ النعمة وصون الكرامة',
ORG_NAME:  'جمعية ...',                            // اسم جهتك (اختياري)
ORG_URL:   'https://...',                          // موقع جهتك (اختياري)
LOGO:      'logo.png',
ORG_LOGO:  'org-logo.png',                         // شعار جهتك (اختياري) — ضع الملف بجانب index.html
SITE_URL:  'https://jisr.example.org',             // رابط المنصة بعد النشر
ABOUT:     'نص التعريف في صفحة التعليمات',
```

احفظ الملف.

## الخطوة ٣: النشر

ارفع الملفات (`index.html` و`logo.png` و`icon-180.png` وشعار جهتك إن وُجد) إلى أي استضافة، مثل:
- **Hostinger** أو أي استضافة: مدير الملفات ← مجلد `public_html`.
- **Netlify Drop** (مجاني): اسحب المجلد إلى صفحة app.netlify.com/drop فتحصل على رابط فوراً.
- **GitHub Pages** (مجاني).

> لا يعمل البرنامج بفتح الملف مباشرة من جهازك بنقرة مزدوجة؛ يجب نشره على رابط يبدأ بـ `https://`.

## الخطوة ٤: التشغيل

1. افتح رابط المنصة واضغط **دخول**، وسجّل برقم جوالك واسمك وبلدتك ورمز سري من 4 أرقام.
2. **أول من يسجّل يصبح المشرف تلقائياً** — سجّل أنت أولاً.
3. من **الإدارة ← الإعدادات**: ضع رابط مجموعة الواتساب، واختر نمط الحجز، وجرّب المنصة.
4. قبل الإطلاق الفعلي: **امسح أغراض التجربة** وأوقف **وضع التجربة** من نفس الصفحة.
5. لإضافة مشرف آخر: يسجّل هو أولاً، ثم **الإدارة ← المستخدمون ← تعيين مشرفاً**.

## تخصيصات إضافية في `index.html`

| ابحث عن | لتعديل |
|---|---|
| `const CATEGORIES` | قائمة التصنيفات |
| `const AREAS` | قائمة البلدات والمناطق |
| `const CONDITIONS` / `const PICKUP` | حالات الغرض وطرق الاستلام |
| `function msgAnnounce` | نص إعلان العرض في مجموعة الواتساب |
| `msgBookedGroup` / `msgBeneficiary` / `msgDonor` | رسائل «تم الحجز» والمستفيد والعارض |
| `--g7` في أعلى الملف | ألوان المنصة |

## ملاحظات

- **أرقام الجوال:** البرنامج مضبوط على الأرقام السعودية (05xxxxxxxx). لاستخدامه في دولة أخرى يلزم تعديل دالة `jisr_norm_phone` في قاعدة البيانات، ودالة `wa` في `index.html`.
- **رسائل الواتساب** تُرسل من جوال المشرف بضغطة زر (الرسالة والصورة جاهزتان)، وليست آلية.
- **الأمان:** الجداول مغلقة، وكل العمليات تمر عبر دوال تتحقق من الجلسة والصلاحية. المفتاح العام في `index.html` آمن بطبيعته. لا تضع مفتاح `service_role` أو كلمة مرور قاعدة البيانات في أي ملف.
- **الخطة المجانية في Supabase** تكفي لبداية التشغيل. المشاريع المجانية تتوقف مؤقتاً بعد أسبوع من عدم الاستخدام، وتُعاد بضغطة زر من لوحة Supabase.
- **النسخ الاحتياطي:** صدّر الجداول دورياً من Supabase ← Table Editor ← Export.
