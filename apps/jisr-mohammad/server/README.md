# جسر محمد — تشغيل الخادم الخاص به
1. أنشئ في Supabase مشروعًا جديدًا باسم jisr-mohammad (لا علاقة له بأي مشروع آخر).
2. من SQL Editor شغّل الملفات بالترتيب: 001 ثم 002 ثم 003.
3. انسخ من Project Settings ← API: عنوان المشروع والمفتاح العام (anon / publishable).
4. ضعهما في index.html عند SUPABASE_URL وSUPABASE_KEY.
5. أول من يسجّل في المنصة يصبح مشرفًا تلقائيًا.
